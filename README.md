**Cryptic Coral Lineage Microbiome Analysis**

This repository contains the bioinformatics and statistical analyses used to characterize bacterial microbiome variation among cryptic lineages of five coral species: *Acropora hyacinthus*, *Acropora tenuis*, *Montastraea cavernosa*, *Pocillopora meandrina*, and *Porites lobata*.

We assess the relative importance of host cryptic lineage identity and sampling site in explaining bacterial community composition across different coral species and geographic regions. Using whole-genome shotgun sequencing data, bacterial communities were taxonomically profiled using Kraken2 and Bracken, and microbiome variation was assessed using Aitchison distances, PERMANOVA, distance-based redundancy analysis (dbRDA), and discriminant analysis of principal components (DAPC).

Our results indicate that cryptic lineage identity is significantly associated with bacterial microbiome composition in some coral species, while sampling location explains a greater proportion of microbiome variation in others. These analyses provide insight into how host genetic variation and geography contribute to bacterial microbiome assembly across cryptic coral lineages.
